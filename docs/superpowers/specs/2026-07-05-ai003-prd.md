# PRD: AI003 Looping ADSR (VCV Rack Module)

## Goal
A VCV Rack port of the AI003 Looping ADSR Eurorack module — a 4-stage envelope generator with a switchable free-running/gated Loop mode, added as a new module inside the existing AI Synthesis VCV plugin package. Panel SVG (black) already exists as a finished asset.

## Features
- **Attack** knob: 20ms–14s (log taper), default 10ms
- **Decay** knob: 20ms–14s (log taper), default 200ms
- **Sustain** knob: 0–10V, default 5V (active only in gated Envelope mode)
- **Release** knob: 20ms–14s (log taper), default 200ms (active only in gated Envelope mode)
- **Mode** switch: 2-position, Envelope / Loop, default Envelope
- **Manual Trigger** button: fires an AD-trigger in Envelope mode
- **Trigger In** jack: fires AD-trigger behavior in Envelope mode
- **Gate In** jack: when patched, switches Envelope mode to full ADSR (Attack → Sustain hold → Release on gate-low)
- **Envelope Out** jack: 0–10V, polyphonic
- **Activity LED**: follows envelope output level

## Behaviour
- **Envelope mode, nothing patched to Gate**: Manual button or Trigger In fires an AD-only cycle (Attack → Decay → 0V). Sustain and Release are ignored entirely in this state, regardless of knob position.
- **Envelope mode, Gate In patched**: standard ADSR — Attack → Decay → Sustain (held while gate is high) → Release on gate-low.
- **Retrigger is legato**: a new trigger/gate-high arriving mid-cycle restarts Attack from the current output voltage, not from 0V.
- **Loop mode, nothing patched to Gate or Trigger**: free-running Attack/Decay loop (2-stage LFO-style), ignoring Sustain and Release.
- **Loop mode, Gate or Trigger patched**: the Attack/Decay loop only runs while gate/trigger is high. On gate/trigger going low, it finishes the current Decay stage in progress, then stops at 0V (does not freeze mid-decay, does not cut off instantly).
- **Polyphony**: if a polyphonic cable is patched to Gate In or Trigger In, the module spawns one independent envelope generator per channel (matching VCV stock ADSR behavior). Envelope Out becomes polyphonic with matching channel count.
- Panel: existing black SVG asset, already finished — do not regenerate or modify layout; wire widgets to the provided SVG coordinates.
- New module added to the existing AI Synthesis plugin package (same plugin.json/plugin.cpp registration pattern as AI001).

## Out of Scope
- Preset system / preset browser (for now)
- Tempo sync on Attack/Decay/Release
- Right-click panel skin switching (for now)
- Selectable envelope curve shapes (exponential only, matching hardware)
- CV/attenuverter inputs on Attack/Decay/Release/Sustain (knobs only, matching hardware)

## Resolved During Design (see [design doc](2026-07-05-ai003-looping-adsr-design.md))
- Mode-switch mid-cycle behavior: switches immediately, no grace period.
- Polyphonic channel-count mismatch between Gate In and Trigger In: Trigger In's
  count wins whenever it is patched.
- Panel SVG: the "finished asset" referenced above is a raw 91,671-line
  Fusion 360/Gerber export with no semantic IDs, not a Rack-ready panel. A
  one-off coordinate-extraction script plus a small hand-built panel SVG are
  used instead — see design doc for details.
